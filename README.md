# website-mirror

Mirror of [PortWatch VI](https://github.com/4lwayz/portwatch-vi), served at https://v3rkku1.github.io/website-mirror/.

`.github/workflows/mirror.yml` checks upstream every 5 minutes and redeploys GitHub Pages when it changes.

## A note to the owner of PortWatch VI

Hi @4lwayz, I'm sorry that I set up this mirror without asking you first. I made it only because some internet providers block the original site, and people behind those blocks still want to follow the tracker. All credit for the site, its content and its code belongs to you. The mirror changes nothing except turning off the visitor stats, so that visitors here don't count against your database.

If you'd like this mirror taken down, or changed in any way, please [open an issue](https://github.com/V3rkku1/website-mirror/issues/new) and I'll do it right away, no questions asked.
